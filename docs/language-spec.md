# fantuan v3 语言规范

fantuan 的源文件是 **Linux x86-64 机器码的十六进制文本**，加上标签和校验和。
编译器 `fantuan` 把源文件打包成 ELF64 静态可执行文件。没有助记符，没有伪指令，
没有表达式，没有可用性。

## 1. 文件与编码

- 源文件扩展名约定为 `.femboy`，UTF-8/ASCII 文本。
- 行分隔符 `\n` 或 `\r\n`。
- Tab 字符出现在任何位置都是错误。

## 2. 行结构

```
[标签:] [字节 ...] [<标签>] ;CK=hh[自由注释]
```

- 空行、纯注释行不需要校验和。
- 含字节的行必须以 `;CK=hh` 注释结尾，且整行只能有这一个注释。
- `;CK=` 后面的两位是小写十六进制，其后可以继续写任意注释文字。

## 3. 字节

- 必须是小写十六进制，两位一组，单个 ASCII 空格分隔。
- 每行最多 16 字节。
- 字节按书写顺序直接进入代码段。

## 4. 校验和

```
CK = (行内所有字面字节之和) & 0xFF
```

`<标签>` 不占字面字节，不参与校验和。校验和只会覆盖 `;CK=` 之前的字面字节。

## 5. 标签

- 标签名：`_start`，或 1–8 位小写十六进制数字。
- 标签定义：名字后跟 `:`，可以单独成行，也可以和字节同行。
- 标签地址 = 它在代码段中的字节偏移（基址 0x400000 + 120 + 偏移）。
- 重复定义、未定义引用都会报错。

## 6. 标签引用（重定位）

`<标签>` 必须满足：

1. 它是本行最后一个 token；
2. 本行的字面字节恰好构成下列白名单模式之一。

| 字面字节 | 类型 | 回填 |
|----------|------|------|
| `eb` | rel8 | `目标 - (位置 + 1)`，超出 [-128,127] 报错 |
| `e8` `e9` | rel32 | `目标 - (位置 + 4)` |
| `70`..`7f` | rel8 | 同 rel8 |
| `0f 80`..`0f 8f` | rel32 | 同 rel32 |
| `b8`..`bf` | abs32 | 目标绝对地址（32 位小端） |

`位置` 指占位字段的字节偏移。占位字段由编译器补零后再回填。

## 7. 编译产物

- 格式：ELF64 `ET_EXEC`，`EM_X86_64`。
- 基址：`0x400000`。
- 镜像：ELF 头 (64B) + 程序头 (56B) + 代码，共 120 字节头部。
- 段：单个 `PT_LOAD`，`PF_R|PF_W|PF_X`，`p_align=0x1000`，无节表。
- 入口：`_start` 标签（可用 `-e <label>` 覆盖）。
- 无解释器、无 libc：程序只能用 Linux syscall。

## 8. 错误信息

所有错误都带行号，语气不保证友好。看不懂就重读本规范。

## 9. 示例

见 `examples/`：

- `exit0.femboy` — 最小程序
- `hello.femboy` — `write` + `exit`
- `jump.femboy` — rel8 跳转
- `loop.femboy` — 循环 + rel8 回跳
